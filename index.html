JARVIS Drive

JARVIS Drive is a personal file-exchange connection for a privately operated JARVIS assistant. It is for the owner's own use and is not a public service.

The owner places files in a dedicated Google Drive Inbox and receives generated files through an Outbox. The connection copies files between those folders and the owner's private server.

This website contains application information only. It does not provide access to the assistant or its files.

Read the privacy notice for details about data access, storage, and revocation.
